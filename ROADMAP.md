# ASCP roadmap

## 0.2 — current working profile

- compact platform capability catalog;
- one-call Direct Flow;
- optional semantic Options;
- signed Negotiate / Prepare / Commit flow;
- free, immediate, prepaid, subscription, postpaid, invoice, clearing,
  sponsorship, and external settlement;
- digest-bound files and attachments;
- signed Direct and Contract receipts;
- resource-local signed audit chains;
- Go reference client, server, conformance runner, OpenAPI, and JSON Schema.

## 0.3 — durable and asynchronous profile

- PostgreSQL reference adapter and migrations tested against the server;
- transactional outbox and worker leases;
- resumable task input endpoint;
- billing and provider reconciliation workers;
- standardized compensation, refund, credit, and dispute resources;
- signed CloudEvents callback profile;
- durable object-storage and scanner reference adapter;
- fuzzing and failure-injection harness.

## 0.4 — interoperability

- TypeScript and Python SDKs;
- language-neutral signing and idempotency golden vectors;
- at least one independent service implementation;
- A2A discovery/delegation and MCP internal-tool composition examples;
- domain profiles for platform investigation, commerce, travel, logistics, and
  real-world coverage/freshness evidence;
- extension and capability registry process.

## 1.0 candidate

- independent security review;
- multi-vendor interoperability event;
- stabilized Direct eligibility, contract, file, billing, and audit semantics;
- production deployment reports;
- long-term governance, disclosure, and conformance-mark policy.
